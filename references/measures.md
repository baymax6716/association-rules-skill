# 指標：定義、計算與解讀界線

本檔與分析指南 `docs/skill-guide.html` 第 2 章一致。skill 的規則表只輸出下列欄位：
前件筆數、共同筆數、support、confidence、後件比例、lift。

## 符號

| 符號 | 意思 |
|:--|:--|
| N | 交易數（問卷為完整案例分析後的人數），**support 的分母** |
| σ(X) | 項目集 X 的出現筆數：包含 X 全部項目的交易數 |
| X ∪ Y | 前件與後件的項目合在一起，例如 {雞蛋} ∪ {吐司} = {雞蛋, 吐司} |
| σ(X ∪ Y) | **同時**包含 X 與 Y 全部項目的交易數（不是「含 X 或含 Y」） |

規則 X → Y 的 2×2 列聯表：

|  | 有 Y | 沒有 Y | 合計 |
|---|---|---|---|
| 有 X | f11 = σ(X ∪ Y) | f10 | σ(X) |
| 沒有 X | f01 | f00 | N − σ(X) |
| 合計 | σ(Y) | N − σ(Y) | N |

## skill 輸出的指標

| 欄位 | 公式 | 意義 | 解讀界線 |
|:--|:--|:--|:--|
| 前件筆數 | σ(X) | 前件出現幾筆 | 太少時 confidence 不穩定（例如 1 筆中 1 筆 = 1） |
| 共同筆數 | σ(X ∪ Y) | 前件與後件一起出現幾筆 | 最低支持度換算成的就是這個筆數 |
| support | σ(X ∪ Y) / N | 規則涵蓋的交易比例 | 太低可能只是巧合；太高的門檻會排除低頻但有意義的組合 |
| confidence | σ(X ∪ Y) / σ(X) | 有前件時，也有後件的比例 | **不考慮後件本來多常見**，一定要和後件比例對照 |
| 後件比例 | σ(Y) / N | 不看前件時，後件本來出現的比例 | confidence 高於它才表示前件「有加分」 |
| lift | confidence / 後件比例 = N σ(X ∪ Y) / (σ(X) σ(Y)) | 相對於獨立情況的倍數 | = 1 獨立、> 1 正相關、< 1 負相關；**不代表顯著、不代表因果**；對稱（X → Y 與 Y → X 相同） |

## 小案例（指南第 7 章，由程式計算）

購物小案例 N = 8：{雞蛋} → {吐司}，σ(雞蛋) = 3、σ(吐司) = 5、σ(雞蛋 ∪ 吐司) = 3。

- support = 3/8 = 0.375
- confidence = 3/3 = 1
- 後件比例 = 5/8 = 0.625
- lift = 1/0.625 = 1.6

對照 {吐司} → {牛奶}：confidence = 4/5 = 0.8 看起來高，但後件比例 0.75，lift 只有 1.0667。
這是「高 confidence 只是後件本來就常見」的例子。

## 教科書例子（可用來向使用者說明）

**茶與咖啡**：1,000 人中 200 人喝茶、800 人喝咖啡、150 人兩者都喝。

- confidence = 150/200 = 75%，看似很高。
- 但整體喝咖啡的比例是 80%，所以 lift = 0.15 / (0.2 × 0.8) = 0.9375 < 1：喝茶反而稍微降低喝咖啡的比例。

**茶與蜂蜜**：200 人喝茶、120 人用蜂蜜、100 人兩者都有。

- confidence = 50%，用 70% 的 confidence 門檻會被刪掉。
- 但 lift = 0.1 / (0.12 × 0.2) ≈ 4.17，是很強的正相關。

## 其他指標（skill 不輸出）

教科書另列多種以 2×2 表計算的指標，例如 PS（leverage）= s(X ∪ Y) − s(X)s(Y)、
φ 係數、cosine（IS）、Jaccard、all-confidence、odds ratio。不同指標對同一組規則的排序可能差很多，
沒有一個在所有情況都最好。skill 第一版只用 support、confidence、lift，避免使用者面對太多指標。
使用者問到時可以說明，但不要用 skill 以外的程式計算後寫進報告。

## 解讀時的提醒

- **因果**：關聯規則只表示共同出現，不代表因果。
- **Simpson's paradox**：合併資料中的關聯，依隱藏變數（門市、年齡層等）分層後可能消失或反轉。
  skill 不做分層檢查；資料來自多個群體時，要在報告的限制中說明。
- **有不有趣**：指標只能排序。「買奶油的人也買麵包」可靠但顯而易見；是否有用、能否行動，要由使用者以領域知識判斷。
- **顯著**：lift > 1 只是樣本比例的比較。第一版不做統計檢定，所以不能寫「顯著」。
